# ADR 0004：使用时间型版本号

日期：2026-07-17

状态：已由 [ADR 0039](0039-remove-hour-from-build-version.md) 取代

## 背景

项目需要能表达频繁内部构建且不依赖传统语义版本发布节奏的版本号。

## 决策

显示版本使用 UTC `yy.mm.dd.hh-v`，同一小时的 `v` 人工递增。CMake `project(VERSION)` 只保存四段数字，完整版本由单一版本配置生成。构建类型可追加 `-dev`、`-test`、`-internal` 或实验后缀。

该格式曾用于 Stage 0-3 的历史构建。自 ADR 0039 起，现行格式移除小时字段，历史报告中的
四段日期版本保持原样。

## 备选方案

SemVer 更适合稳定公共 API 发布，但当前不能表达项目所需的构建时间排序，因此暂不采用为主版本。

## 影响

窗口、日志、崩溃报告和产物显示完整版本；vcpkg manifest 记录不带构建类型后缀的规范版本。

## 后续风险

人工编译号可能漏增，必须用测试检查版本来源一致性。
