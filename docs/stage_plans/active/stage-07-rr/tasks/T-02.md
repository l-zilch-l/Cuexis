2. 对每个 ID 给出原陈述、当前代码或版本来源、对应修改、历史依据及需后续取证的部分。汇合后由集成者生成 MAP 和 AGENTS 状态块并执行验收。

## 任务级验收

在集成副本运行 `python -B tools/verification/gen_docs_map.py` 后，`python -B tools/check_docs.py`、`python -B tools/verification/gen_docs_map.py --check`、`python -B tools/verification/check_docs_facts.py --list` 退出 0。逐项清点 drift 输出，涉及本卡的现行错误版本和状态须清零。隔离副本在 `docs/api/diagnostics-identity-and-compatibility.md` 的现行正文插入一行与权威值不同的 SDK API 字面量，`--list` 应指出该文件、行和值。版本漂移在现有检查器中是警告，反例匹配输出。历史行应维持原值和历史标记。
