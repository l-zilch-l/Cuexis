## 目标

`DOC`；逐眼核对阶段证据和相邻阶段交接，形成可接受的退出记录。采用见[计划](../plan.md#唯一派单授权入口)。

## 输入

[阶段验收](../acceptance.md)、[登记册](../findings.md)、[报告模板](../../../../templates/report.md)、[阶段报告索引](../../../../stage_reports/stages/stage-07-rr/README.md)、[Stage 7.5 入场条件](../../stage-07-5/plan.md#2-前置基线与依赖)与 [Stage 8 前置](../../../future/stage-08/plan.md)。从 `out/review/stage-07-rr/` 读取 T-01 基线和各卡证据。

## 写域

采用后由集成者写 `docs/stage_reports/stages/stage-07-rr/YYYY-MM-DD-exit-and-handoff.md` 和同目录 `README.md`、本阶段 `findings.md` 和退出状态、`docs/{CURRENT_STATUS,HANDOFF,ROADMAP}.md` 及计划索引和相邻阶段的交接链接。正式归档时同步 `tools/verification/{check_docs,check_plan_schedule}.py` 中本阶段的固定路径/状态引用及生成路由。相邻阶段的能力与授权范围保持原约束。

## 步骤

1. 按 A-01–A-05 建证据索引。每行绑定任务/发现 ID、T-01 的 SHA 和合同修订、卡级报告路径、适用 preset/平台、fixture、正反例日志和回滚点。对较早批次记录取证 SHA 到退出基线的变更，涉及已验对象时附重跑结果。核对 T-07 删并清单、T-08 实际消费者/导出与逐组退役记录。
2. 对 P0/P1 逐条链接满足条件的修复、限制或已接受延后。RR-F401 的保存保留修复随 [T-16](T-16.md) 采用（其写域已含 `engine/chart/src/chart_writer.cpp` 与图表 round-trip 测试）；RR-F420 的 `exactLossCount` 与 PD-4 既定语义冲突，须先由 owner 定「exact」判据。两者都以具名延后进入 A-05，恢复条件随退出记录由 owner 接受。P2 延后写明责任、进入条件与恢复门槛。按模板生成退出报告供 owner 接受，记录接受人、日期和接受的范围。阶段受限退出仍引用原失败或缺证据。
3. 获得退出接受后同步状态和路由。CURRENT_STATUS 链接报告、已接受范围和遗留。HANDOFF 写明现行任务、下一步、阻塞和验证状态，保留已有 Plan 拆分规则。Stage 7.5 入场引用这份退出报告与接手项，Stage 8 继续引用独立的 Stage 7.5 退出门槛。归档时把已接受阶段计划移至 `docs/stage_plans/completed/stage-07-rr/`，更新活动指针和硬编码门禁路径，按文档政策为旧入口留跳转，历史报告与 manifest 保持原位置。`NEXT` 合同以候选包链接移交，实施按后继采用。

## 任务级验收

- 在退出快照执行 `python -B tools/verification/gen_docs_map.py`，再执行 `python -B tools/check_docs.py`、`python -B tools/verification/check_plan_schedule.py --stage-dir docs/stage_plans/completed/stage-07-rr`、`python -B tools/verification/gen_docs_map.py --check`、`python -B tools/verification/check_docs_facts.py --list` 和 `git diff --check`，均退出 0。接受前核对时，调度命令使用当前阶段目录。索引的每项通过须回溯至与对象一致的 SHA、证据与接受记录。
- 在退出证据的隔离副本分别拿掉一项必需负例日志、一个具名延后的接受记录。按 A-05 复核时分别判该项缺证据和延期未接受，均保持 active。恢复两份记录后再核对 Stage 7.5 链接的接受范围和报告一致。人工核对结论及缺证据原因，文档链接检查单独记账。

## 证据

`out/review/stage-07-rr/T-09/` 保存 A-01–A-05 证据索引、接受记录、阴性复核和状态差异。归档报告通过阶段报告索引可达。

必要记录缺失、延后未经接受、活动指针或交接范围与报告冲突时保持 active。涉及历史证据文件或 manifest 变更时撤回对应变更。
