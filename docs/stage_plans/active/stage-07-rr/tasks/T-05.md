## 写域

合同点名的几何实现、`engine/playback/src/frame_layout_internal.hpp` 的纯值 `composeFrameProjection`（inline，含 R/Q/Pout）、`engine/render_opengl` GL helper、`tests/playback/` 与 `tests/render/` 对应用例。只接几何、投影组合和 GL 矩形；materializer 写快照及宿主接线由 T-06 完成，不接 Chart 字段、旧入口或 Player CLI。以旧谱和内存值证明，不依赖 T-11/T-13、新 schema 或新成品 target。

本卡先在 `engine/playback/experimental_include/cuexis/playback/experimental/frame_layout.hpp` 定义几何值和两个几何函数。写域含 `engine/{playback,render_opengl}/CMakeLists.txt`、`tests/{playback,render}/CMakeLists.txt` 与 `cmake/VerifySharedExports.cmake`：两种 flavor 共用几何实现，逐函数导出 `computeContentRect` 和 `computeFrameLayout`，两边的 shared 门禁先只要求本卡的这两项。默认 `debug` 给实际用头的目标（含 `cuexis_playback_tests`、`cuexis_render_opengl_tests`）显式加 `PRIVATE` include 根；不进默认 `FILE_SET` 或传播到普通源码消费者。T-06 接续同一份头与符号。

验收接线另含根 `CMakeLists.txt` 中既有测试目标的具名 `ALLOWED`：`rr_frame_layout` 在 `tests/render/CMakeLists.txt` 的 `cuexis_render_opengl_tests` 内新增并沿 Catch 注册，所需 Playback 几何及真实 GL 上下文依赖仅加到测试的 PRIVATE 边；复用现有库与上下文建立路径，不建新测试框架。

## 步骤

1. 落合同定义的像素矩形和整数比例运算、四旋转、首项/最大物理面积/显式项选择；接实际目标像素，不使用逻辑窗口坐标冒充 framebuffer。
   同卡实现合同的 `composeFrameProjection`：输入基础 P 和已验证非空布局，输出唯一 Pout=Q*R*P。测试目标 PRIVATE 读该非安装头，两个 flavor 复用，helper 不导出。旧谱 Q=I，90°/270° 的 reciprocal aspect 与随后 R 都执行；旧谱 0° 直接返回原矩阵。T-06 接此实现，不重新发明 Q。
2. 按合同顺序实现宿主裁剪清屏、内容区域绘制和状态归还，覆盖提前返回。借用 FBO 只接合同限定的 RGBA8 color0 + DEPTH_COMPONENT24/32F 单样本 renderbuffer；先验实际附件/尺寸/完整性，再显式设 draw buffer，并归还原全部 draw routes 及触及状态。

## 任务级验收

先配置 `debug`，执行 `cmake --build --preset debug --target cuexis_render_opengl_tests`，再用 `ctest --test-dir out/build/debug --no-tests=error -N -R '^rr_frame_layout$'` 确认注册。下列 GL 正反例须使用能创建实际上下文的驱动，覆盖该用例继承的 `SDL_VIDEODRIVER=dummy` 设置；上下文不可用时记录未执行，不以跳过或纯值测试替代像素验收。

实施时新增、当前未执行：`ctest --preset debug --no-tests=error -R '^rr_frame_layout$'`，执行[向量 R5-01–04、R5-06 的内存比例对照、R5-09 与 R5-10 的纯几何/逆算](../contracts/render-player-writer.md#兼容目标及向量)。例如 host `(100,50,1280,721)`、extent `1600×1000`、21:9，内容绝对矩形为 `(100,136,1280,548)`，GL 中为 `(100,316,1280,548)`；失败也恢复预设 GL 状态，区域外像素不变。溢出与零比例拒绝，空矩形不绘制。正方形中 `2:1` 与 `1:2` 平手取首项；90° 下 Exact 仍匹配未旋转作者比。按向量核对非零 host 原点、整数取整、Q 和边缘不命中。另执行 R5-11：FBO complete 且初始 draw buffers 全为 GL_NONE 仍应画到 color0，返回精确恢复 GL_NONE 及各绑定；color1-only、缺 depth、texture、多样本、depth-stencil、尺寸不符各在 clear/draw 前拒绝且像素不动。有效附件 draw 失败也归还路由和全部触及状态。

R5-10 另以 90° 且非单位 Q 的向量验证最终 Pout；由完整 `(Pout*V)^-1` 一次反算还原同点，预先逆 Q/R 再逆 Pout 的阴性应失败。基础 P 的 Pyy 与最终矩阵条目分开断言，旋转后不可再把 Pout.yy 当竖向透视系数。未接 materializer 前只声明纯值向量通过。
