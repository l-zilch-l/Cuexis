# Cuexis RPA 与表现术语

状态：current glossary
更新日期：2026-10-16

本页只解释领域词义；语义合同见 [RPA 补充](../formats/rpa-execution-contract.md)。

| 术语 | 含义 |
| --- | --- |
| 捕获时刻（capture-time） | 输入实际进入捕获管线时的校准会话时刻 |
| 原始 Tick | 一次输入发生首次取得的 Tick，交付或转发不改变它 |
| 发生身份（occurrence identity） | 能区分同一来源、同一 Tick 内多次相同转换的身份 |
| 执行 Tick（dispatch Tick） | 该输入实际参与确定性执行的逻辑 Tick |
| 完整前缀 | 已证明没有遗漏且每项都有处理结局的连续历史 |
| 控制切点（control cut） | 控制明确划定的运行历史边界，包含时间与记录位置 |
| 暂停轨迹（PauseTrace） | 暂停期间按顺序捕获的真实输入转换历史 |
| 恢复状态对齐（reconciliation） | 用暂停轨迹处理真实中断，使恢复后的游戏状态与物理输入相容 |
| 直接续跑资格 | 当前会话通过Resume继续本局的资格；可取得历史结果不代表仍具有该资格 |
| 判定完成 | 所要求的判定阶段已按合同终结，与音轨结束分别判断 |
| 呈现回执（present receipt） | 对一次设备提交操作结果的确认，不证明用户已经看见 |

## 表现与交付

以下词义用于 [PD 设计](../stage_plans/active/stage-07/presentation-decoupling-design.md)讨论，
不表示新的 SDK 接口已经实现。

**已提交表现状态**：一次已完成操作所确定的画面内容及其来源；交付请求不会重新推进它。
_Avoid_：把最后呈现的画面称为当前状态。

**状态修订号**：区分同一会话内不同已提交表现状态的身份；它不表示呈现次数或成功更新次数。
_Avoid_：帧号。

**表现重建目标**：一次重建操作要求恢复到的确定时间与内容状态；目标尚未完成时不代表当前画面。
_Avoid_：把请求的目标时间称为已提交时间。

**表现重建进度**：恢复到重建目标的过程中已完成的工作范围；它不具备完整画面的交付资格。
_Avoid_：中间成功帧。

**完整可交付修订**：其必需表现域已共同完成、可作为完整画面物化来源的状态修订；实际构帧仍可能失败，呈现仍取决于交付绑定。
_Avoid_：把重建进度或设备就绪称为状态完成。

**交付绑定**：某个消费者在已确认控制和资源条件下使用画面内容的许可；不改变内容的来源。
_Avoid_：将绑定改变称为重新求值。

**消费注册实例**：一个消费者本次加入会话的身份；同一窗口或设备退出后重新加入，属于新的注册实例。
_Avoid_：用设备实例或请求序号代指消费注册。

**保留画面**：呈现端最后一次成功调用所使用、仍被保留的画面；可以落后于当前状态。
_Avoid_：最新结果。

**表现作用域**：一段可以共同解释表现激活身份的范围；它的替换与单纯暂停是不同事件。
_Avoid_：把每次控制序号变化都称为表现重建。

**UntilReset**：没有时间到期点的表现寿命，仍受明确重置、替换和取消规则约束。
_Avoid_：最大 Tick 到期。
