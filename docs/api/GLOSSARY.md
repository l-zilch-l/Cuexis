# Cuexis RPA 术语

本页只解释领域词义；语义合同见 [RPA 补充](../formats/rpa-execution-contract.md)。

| 术语 | 含义 |
| --- | --- |
| 捕获时刻（capture-time） | 输入实际进入捕获管线时的校准会话时刻 |
| 原始 Tick | 一次输入发生首次取得的 Tick，交付或转发不改变它 |
| 发生身份（occurrence identity） | 能区分同一来源、同一 Tick 内多次相同转换的身份 |
| 执行 Tick（dispatch Tick） | 该输入实际参与确定性执行的逻辑 Tick |
| 完整前缀 | 已证明没有遗漏且每项都有处理结局的连续历史 |
| 控制切点（control cut） | 控制明确划定的运行历史边界，包含时间与记录位置 |
| 暂停轨迹（PauseTrace） | 暂停期间按顺序捕获的真实输入转换历史 |
| 恢复状态对齐（reconciliation） | 用暂停轨迹处理真实中断，使恢复后的游戏状态与物理输入相容 |
| 直接续跑资格 | 当前会话通过Resume继续本局的资格；可取得历史结果不代表仍具有该资格 |
| 判定完成 | 所要求的判定阶段已按合同终结，与音轨结束分别判断 |
| 呈现回执（present receipt） | 对一次设备提交操作结果的确认，不证明用户已经看见 |
