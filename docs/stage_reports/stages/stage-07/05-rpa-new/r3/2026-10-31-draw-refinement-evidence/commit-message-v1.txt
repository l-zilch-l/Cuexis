Build neutral draw commands in place without ordered copies

The ordered pass no longer materialises a second OrderedDraw array and then
moves every command into the summary. Each pass now reserves its final
summary vector and appends the command it just built, so the opaque and
transparent arrays are written once and the move-transfer loop disappears.

Ordering, digest and the is_sorted early exit are unchanged; only the
intermediate owning copies are gone.
