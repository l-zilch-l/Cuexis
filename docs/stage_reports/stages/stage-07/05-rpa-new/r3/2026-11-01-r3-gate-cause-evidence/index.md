# R3 两项超界的根因证据（2026-11-01）

本目录保存根因分析的数值证据。它回答两个问题：179 ms 的 Pause 超界落在哪，以及读取相对门那 17 % 是
由什么构成。所有用于取得这些数字的仪器诊断与产品补丁都已回滚。

- [返回根因分析报告](../2026-11-01-r3-gate-cause-analysis.md)

## 文件

| 文件 | 内容 |
| --- | --- |
| `attempt/cause-analysis.json` | 四个读取消融（E0–E3）的比值与结论、首次 Pause 的三段拆分、该帧 GPU timer 读数、隐藏/可见窗口对照、预热帧实验的两组读数、以及回滚清单 |

## 关键数值

- Pause：`pause()` 258 µs + 冻结 `sample` 49 µs + 冻结 `present` 175 836 µs；该帧 `gpu_render` 1.024 µs。
- 预热 1 帧 live 后：停顿转移成 174 870 µs（那帧 live），首次冻结 present 只要 713 µs。
- 读取消融：E0 1.0175、E1 **0.8247**、E2 1.0068、E3 1.0392；E1 是"完全不读 registry"。

## 边界

- 消融比较是同版本内的补丁对照，不参与任何正式门判定，也不与 pre-PD 臂的正式比值相加。
- 三次成对比较只用于判断量级；这不是显著性结论。
- 预热帧实验在探针里完成，不是产品改动。
