## 2. 计划项对照

1. `cuexis_presentation_renderer` 是 Playback 与底层 render 之上的内部静态库。
   它不进入公共或静态实现安装列表，头文件不含 SDL 或 OpenGL。
2. Playback、Runtime 和底层 render 不包含这层头文件。共用 draw builder 在新层。
   OpenGL 仍保留自己的绘制路径，没有反向依赖新层。
3. `IPresentationRenderer` 覆盖 capability、候选 prepare、`accepts`、activate、discard、
   统一帧提交、present、resize、rebuild 和 close。submit 与 present 分开。
4. 同时最多一个 outstanding candidate。候选析构会 discard。rebuild 使旧 renderer
   generation 失效，并清掉已保留资源。零尺寸表面暂停提交。resize 不改 Playback 身份。
5. 可恢复 present 失败保留 active cache。不可恢复失败把表面标为 lost，直到 rebuild。
   close 不关闭应用窗口，也不能在候选尚未丢弃时完成。
6. 测试 renderer 与排序实现消费同一 `buildPresentationCommands`。opaque 按 id，
   transparent 按深度从远到近。digest 字段顺序与现有 OpenGL summary v1 相同。
