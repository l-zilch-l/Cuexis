## 2. 计划项对照

1. `cuexis_player_support` 拥有 UserPreferences、AudioDeviceProfile、`ResolvedAppConfig`、
   `EffectiveSettings` 和 `ResolvedSessionConfig`。它不进入安装列表。
2. 用户目录、同目录临时文件、校验后替换和进程间锁已经接上。锁句柄保持打开，直到本次
   写入结束。未来版本原件不覆盖。损坏或缺失偏好使用唯一代码默认值。
3. Player 在 Session prepare 前冻结请求配置和本次执行配置。窗口、全屏、vsync 来自请求值。
   子系统创建后记录实际窗口和音频是否打开。gain 通过 `applyGain` 生效。
4. Session identity 只编码 clock mode 与实际消费的校正。日志不写用户目录路径。
5. 显式设备按 driver 与名称精确匹配。零个或多个匹配都失败。instance id 只在本次打开前使用。
6. CuexisAudio 在进入 RuntimeTimeline 前对位置副本应用一次校正。音频 smoke 的 Seek 使用
   反向换算。ChartClock 不消费校正。热拔插导致的缺失、歧义和格式变化都失败，不改开另一台设备。
7. 保存文件和运行时 apply 是分开的。发布后的配置对象不回读磁盘上的后续修改。
