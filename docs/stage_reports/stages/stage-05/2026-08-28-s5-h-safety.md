## 1. 结论

S5-H 已把 spec 预算、warmed 分配合同、opt-in 趋势探针和 Linux sanitizer shader-tools 覆盖接到
现有 Playback / `cuexis_shader` 入口。越界测试用 header claimed size 与
`content.provider.too_large`，不分配 64 MiB fixture。Shader `decodedByteCount` 与 Parameterized
Material 累计改为 `checkedAddU64`。warmed Unlit 继续 Stage 4 零新增合同；warmed Parameterized
`update()` / `extractFrame()` 冻结为零新增，且热帧不得再次向 ContentProvider fetch。Playback
热路径仍不链接 shaderc、不打开缓存目录、不增长 cache map。`CUEXIS_RUN_PERFORMANCE_PROBE=1`
记录最大合法 keyword/parameter/binding 计数下的 prepare 与热帧内存趋势，不设机器硬阈值。
Linux Quality 增加 `headless-sanitize-shader-tools`。SDK API 保持 `0.7.0`。本报告不是 Stage 5
completion report。
