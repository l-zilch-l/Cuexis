### ST01：裸 `new`

Agents.md / [CODE_POLICY.md](../../../guides/CODE_POLICY.md)：不得使用裸 `new`/`delete` 穿越模块边界。

```cpp
// engine/cxc/src/cxc_package.cpp:786
return std::shared_ptr<CxcContentProvider>{new CxcContentProvider{data_}};
```

指针立即被 `shared_ptr` 接管；这是本区间新模块中仅见的裸 `new`。

### ST02：未命名丢弃的 `Result` 解引用

[CODE_POLICY.md](../../../guides/CODE_POLICY.md)：禁止忽略 Result；无需处理时必须显式调用命名清晰的
discard/log helper。`result.hpp` 没有该 helper。

```cpp
// engine/animation/src/animation_sampler.cpp:221
const auto zero = *chart::RationalBeat::create(0, 1);

// engine/chart/src/chart_v4_resolver.cpp:902
const auto one = *RationalBeat::create(1, 1);
```

两处均把 `create(0,1)` / `create(1,1)` 当作不变量。失败时是未定义行为，而不是稳定 Error。

### ST03：SHA-256 重复

气味：Duplicated Code。`engine/chart/src/sha256_internal.cpp` 与
`engine/cxc/src/cxc_hash_internal.cpp` 均实现 `Sha256::update` / `finish`。

### ST04：可移植路径重复且已漂移

气味：Duplicated Code。`foldAscii` / `isWindowsReservedSegment` / 路径遍历同时出现在
`engine/chart/src/chart_v4_reader_internal.cpp` 与 `engine/cxc/src/cxc_path_internal.cpp`。
CXC 额外拒绝 `clock$` / `conin$` / `conout$`，Chart 侧没有。

### ST05：slerp 重复

气味：Duplicated Code。`animation_sampler.cpp` 与 `animation_mixer.cpp` 有近乎相同的 quaternion
lerp/slerp/normalize（`dot > 0.9995`，相同权重）。

### ST06：AnimationSystem 中间人

气味：Middle Man。`engine/animation/src/animation_system.cpp` 的 `AnimationSystem::evaluate`
只转发 `AnimationMixer::evaluate`。

### ST07：公开构造函数暴露 `detail`

气味：Speculative Generality / 泄漏。`cuexis_cxc` 不是安装组件，但模块头仍把内部数据类型放进
公开构造函数：

```cpp
// engine/cxc/include/cuexis/cxc/cxc_package.hpp:81
explicit CxcPackage(std::shared_ptr<const detail::CxcPackageData> data) noexcept;
```

### ST08：Resolver 承担多种职责

气味：Divergent Change。`engine/chart/src/chart_v4_resolver.cpp` 约 1411 行，同一翻译单元拥有
CXT import、参数、lowering、capability 与 identity。

## 4. Spec

| ID | 类别 | 问题 | 状态 |
| --- | --- | --- | --- |
| SP01 | 缺失或部分 | HostOverride 未出现在 Playback 公共门面 | open |
| SP02 | 未要求 | 构建版本去掉 hour，引入 ADR 0039 | open |
| SP03 | 实现与合同不符 | 采样前把 Beat 经 Farey 近似 | open |
| SP04 | 实现与合同不符 | StudioPreviewOverride 未限制在 Studio/preview Session | open |

### SP01：宿主覆盖不在宿主门面

`PropertyResolver` 与 `RuntimeSession` 实现了 HostOverride、StudioPreviewOverride 和
`BasePropertyCommand`。`engine/playback/include` 没有 Override / `OverrideToken` 符号。

合同：Stage 4 计划 §4「实现 HostOverride 与 StudioPreviewOverride Token，以及
`BasePropertyCommand`」；§5「宿主只通过稳定 ObjectId、PropertyId 和 OverrideToken 操作，
不访问 World 或最终 Component」；S4-D「公开 HostOverride API 只允许稳定 ObjectId、PropertyId
和 OverrideToken」。外部 Playback 宿主无法申请或释放覆盖。

### SP02：构建版本身份变更不在本阶段交付单

ADR 0039 与 `tools/update_version.py` 把身份改为 `yy.mm.dd-v`。CFU 计划 §1 交付列表与 Stage 4
§4 / §6 均未要求改变版本身份。

### SP03：采样不是精确绝对 Beat

```cpp
// engine/runtime/src/runtime_session.cpp:1015-1024
auto chartBeat = chart::approximateRationalBeat(beatSample->beat);
...
auto mixed = animation::AnimationSystem::evaluate(
    *state.animation, *chartBeat, ...);
```

`approximateRationalBeat` 默认 `maxDenominator` 为 `1000000`。合同：Stage 4 计划 §4「对
continuous Track 与 step Track 做确定性采样」；CFU 计划 §12「时间跳转从绝对时间重建状态」。
Clip 局部时间是 TimingMap double 的 Farey 舍入，Beat 边界可以偏移。

### SP04：StudioPreviewOverride 未按 Session 类型收口

`RuntimeSession::acquireOverride` 在任意 Session 上接受 `OverrideKind::StudioPreview`
（`engine/runtime/src/runtime_session.cpp:1349-1352`）。合同：Stage 4 计划相关批次说明
「StudioPreviewOverride 使用同一协议，但只存在于 Studio/preview Session，不进入 Chart 或
FrameDigest 语义。」
