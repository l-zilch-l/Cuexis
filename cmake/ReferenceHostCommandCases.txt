# Reference host command cases, one declaration per line.
#
# This file is the single definition of the case set. The gate reads it to build
# its expectations and the independent parser test reads the same file with its
# own algorithm, so the two share data rather than conclusions.
#
# Syntax
#   * One declaration per line: <id>|<kind>|<flags>
#   * Exactly two '|' separators on every declaration line.
#   * The flags field is legitimately empty; a line ending in '|' declares an
#     empty flags field, and a line with only one separator is malformed.
#   * id     - lower-case words separated by '-', matching ^[a-z][a-z0-9-]*$.
#              The id names the fixture files when kind is cmd.
#   * kind   - exactly one of: cmd invocation generated legacy
#   * flags  - zero or one lower-case flag word matching ^[a-z][a-z0-9-]*$.
#              Multiple flags are not used today and the gate reads only the first
#              field, so a ';' here would silently drop the rest. Keep it to one.
#   * Blank lines are ignored. A line whose first non-blank character is '#' is a
#     comment. Trailing '#' comments are not supported; '#' is only a comment at
#     the start of a line.
#   * Leading and trailing whitespace on a line is stripped before parsing.
#   * CRLF and LF line endings are both accepted.
#
# Paths are repository-relative and resolved by the gate; this file holds no
# absolute paths.
