# ADR 0016：Cuexis 使用 Apache License 2.0

日期：2026-07-17

状态：已接受

## 背景

Cuexis 是免费开源项目，需要明确使用、修改、分发、专利和第三方依赖义务。维护者不以盈利为目标，但符合开源定义的许可证不能限制下游商业使用。

## 决策

Cuexis 采用 Apache License 2.0。正式公开发布前加入官方完整 LICENSE 文本，并按需要维护 NOTICE 和 THIRD_PARTY_NOTICES。

第三方依赖按 `docs/guides/DEPENDENCY_POLICY.md` 审查。传播性许可证未经明确兼容分析和 ADR 不进入正式发布依赖。

## 备选方案

MIT 更简短，但 Apache-2.0 提供更明确的专利授权与贡献条款。非商业许可证不符合通用开源定义，因此不采用。

## 影响

下游可以在遵守许可证的前提下商业使用。源码文件和发布流程需要保留版权、许可证及修改声明。

## 后续风险

本 ADR 不是法律意见。引入复杂许可证依赖或接受大型外部贡献时仍需单独审查。
