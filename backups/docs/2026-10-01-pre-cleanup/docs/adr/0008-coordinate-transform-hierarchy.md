# ADR 0008：坐标、Transform 与父子层级语义

日期：2026-07-16

状态：已接受

## 背景

World、Behavior、Animation、粒子和渲染都需要共享相同的空间语义。若坐标系、单位、矩阵顺序或层级失败策略不统一，同一谱面会在不同 System 和后端中产生不同结果。

谱面还可能引用已被旧版本、第三方工具或手工编辑删除的父对象。为了兼容这些谱面，单个缺失引用不应阻止其他独立对象运行，但降级行为也不能静默改变对象的空间含义。

## 决策

Cuexis 使用右手坐标系，`+X` 向右、`+Y` 向上、`+Z` 向后，默认相机朝向 `-Z`。世界尺度为 `1 unit = 1 meter`。

运行时使用列向量约定：

```text
Local = Translation * Rotation * Scale
World = ParentWorld * Local
```

运行时旋转使用 Quaternion，角度计算使用弧度；编辑器向用户显示度。图形 API 的裁剪空间差异由具体渲染后端转换。

Reparent 必须显式选择 `KeepLocal` 或 `KeepWorld`。删除带子级的 Entity 必须显式选择 `DestroySubtree` 或 `DetachChildrenKeepWorld`。两个操作均不得提供隐含默认模式。

需要保持世界变换的操作必须能够把结果无损表示为局部 TRS；若出现无法表示的剪切，操作在修改 World 前失败并报告错误。

层级禁止自身引用和循环引用。循环引用属于谱面编译错误。

编译器必须先为完整文档建立对象 ID 索引，再解析层级；父对象在文件中的前后顺序不影响引用结果。当父 ID 在完整索引中确实不存在时，编译器执行兼容性降级：

```text
编译继续并可以成功
生成 Warning 级别结构化诊断
不编译该孤儿对象
不编译以该对象为祖先的所有后代
其他独立有效对象正常编译
```

该警告必须进入启动日志、Chart Validator 和运行时调试界面，且包含缺失父 ID、被跳过的子树根 ID 和跳过数量。编译器不得把孤儿对象静默改挂到根节点。

## 备选方案

### 缺失父对象时终止整个谱面编译

拒绝。该策略过于严格，会使包含局部损坏或旧引用的谱面完全无法运行。

### 把孤儿对象挂到根节点

拒绝。这会在没有作者授权的情况下改变局部变换的参考空间，可能产生严重但不易定位的视觉错误。

### 仅跳过孤儿对象并保留其后代

拒绝。后代依赖已经缺失的变换链，继续编译会改变原有层级语义。

### 删除父级时采用固定的隐式策略

拒绝。编辑器、运行时卸载和游戏逻辑需要不同语义，隐式策略容易造成误删或世界变换突变。

## 影响

```text
Transform、Behavior 和 Animation 必须遵守相同坐标及矩阵约定
层级修改 API 需要返回可检查的成功或错误结果
Chart 编译结果需要同时携带产物和 Warning 诊断
Chart Validator 与调试界面需要展示可恢复诊断
谱面测试需要覆盖缺失父级、级联跳过、自引用和循环引用
```

## 后续风险

非均匀缩放与旋转组合容易产生剪切。初版不引入完整仿射变换 Component，因此保持世界变换的操作可能合法失败；调用方必须处理该错误。

稳定对象 ID 已由 ADR 0010 确定为规范格式中的 UUIDv7；父级诊断和子树跳过要求编译阶段先建立完整对象引用图。
