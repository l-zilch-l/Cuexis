## 1. 结论

CFU-E2 已关闭。Playback 现在可以从 text、typed project-document、filesystem 和 CXC source 对 Chart
v4 执行 load、parameter resolution、CXT import lookup、capability preflight 和既有 Runtime prepare。
空动画、静态和参数化 Transform/Camera v4 可成功 prepare/load；任意非空 Clip、CXT import、Binding、
Layer 或 Instance 在 Stage 4 前仍以稳定 capability 诊断拒绝。

该关闭不包含 `PreparedSemanticIdentity`、active identity observation、CFU-E3/E4、CFU-D3、动画采样或
混合、完整 CXC 产品支持、公共 package API、完整 CFU-E 或 Stage 4。

## 2. Public prepare surface

安装 Playback 头实现了 E0 冻结的 parameter 与 options surface：

```text
ChartParameterNumber / ChartParameterRational / ChartParameterWeight
ChartParameterValue / ChartParameter / ChartParameterSet
PlaybackPrepareOptions
prepareLoad / prepareReload / load / reload options overloads
capabilityChartV4 / capabilitySourceCxcV1 / capabilitySourceCxtV1
```

number、rational 和 weight 保持独立 type tag；公共头不暴露 `chart::RationalBeat`、JSON DOM、CXC
package、archive handle 或 resolver。原无 options overload 全部保留并委托空
`PlaybackPrepareOptions{}`；`TypedPlaybackProject` 三字段 aggregate layout、FrameSnapshot 和
FrameDigest v3 均未改变。

## 3. Prepare ordering and resolved content

Playback 的 v4 prepare 顺序固定为：

```text
entry Chart lookup
Chart v4 parse and semantic validation
public ParameterSet -> typed ChartParameterInput
project-document table -> CXT lookup
ChartV4Resolver parameter/import/lowering/budget validation
capability preflight
ChartCompiler projection into existing ChartRuntime
existing resource, RuntimeSession and presentation prepare
```

因此 malformed Chart、unknown/duplicate/missing/type/range parameter、非法 Rational/weight、缺失 CXT
和 lowering/budget 错误都先返回原 typed diagnostics，不会被笼统 capability 错误遮蔽。v1/v2/v3
继续走 `ChartLoader`；向旧格式提供非空 ParameterSet 会稳定返回 `chart.parameter.unknown`。

解析后的 `AnimationProgramInput` 只保存在私有 `PreparedPlayback` candidate state。Chart compiler 没有
动画求值分支，Runtime/World 没有接收 Clip/CXT/Binding/Layer 数据，`engine/animation/` 也没有解析
JSON、CXC 或 CXT。

## 4. Capability and transaction boundary

默认 Playback capability set 增加 `cuexis.chart.v4`、`cuexis.source.cxc.v1` 和
`cuexis.source.cxt.v1`。CXC source 额外要求 CXC source capability；CXT import 额外要求 CXT source
capability。E2 没有声明 `cuexis.animation.clip.v1` 或 `cuexis.animation.layers.v1`，因此所有非空动画
在 Chart validation 后、Runtime/World 发布前以 `playback.capability.unsupported` 失败。

静态和参数化 v4 复用既有 ChartRuntime、RuntimeSession、presentation candidate 和 commit token。
失败 reload 不替换 active content；成功 options reload 使用新的冻结 parameter value。E3 才会保存
canonical identity components、获取并验证实际 resource identity manifest，并组装最终
`PreparedSemanticIdentity`。
