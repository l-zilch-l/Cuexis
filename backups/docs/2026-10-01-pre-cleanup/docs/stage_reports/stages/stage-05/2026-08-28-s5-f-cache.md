## 1. 结论

S5-F 已在可选 `cuexis_shader` 中实现 `CXSCCH01` Writer/Reader、规范缓存键、显式目录存储，
以及失败保留上一 Pipeline 的 Worker 编译 / owner-thread noexcept swap。importer
`--cache-dir` 写出 SPIR-V + GLSL 330 + GLSL ES 300 + 规范化 reflection。删除缓存后同一键
重建出相同字节。`shader.cache.tool_mismatch` 不复用旧工具版本。`compileEnabled=false` 且
缺缓存时返回 `shader.cache.missing` 且不编译。Playback 热路径仍不链接或调用编译器。
OpenGL adapter 仍报告 `parameterizedMaterial=false`，未消费 `CXSCCH01`。

## 2. 交付

```text
CXSCCH01 v1 envelope: magic CXSCCH01, cacheVersion=1, reserved 0, totalByteCount
body: identity, importer, sorted targets/keywords, entries, sorted tools,
      SPIR-V both stages, GLSL 330 / ES 300 both stages, reflection, 32-byte key
canonical key SHA-256, length-prefixed:
  "cuexis.shader.cache.v1\0", 32-byte source identity, importer,
  sorted unique targets, sorted unique keywords, vertex/fragment entry,
  sorted tool (name, version) tuples
filename: lowercase hex(key) + .cxscch01
directory explicit (importer/Player); no project-tree scan
ShaderCacheStore load/store: tmp+rename; missing -> shader.cache.missing
corrupt envelope -> shader.cache.key_invalid
stale tools -> shader.cache.tool_mismatch (adoptCacheRecord / load)
ShaderPipelineCache: Worker compile, activate() noexcept unique_ptr swap
compileEnabled=false + miss -> shader.cache.missing, no compile
compile/store fail with active present -> shader.hot_reload.failed, active kept
diagnostics capacity 1,024; sentinel shader.diagnostics.limit_exceeded
undeclared keyword -> playback.presentation.shader.keyword_invalid; no cache file
cuexis_asset_importer --cache-dir DIR [--identity HEX64]
standalone identity = length-prefixed SHA of sources/entries/keywords
  (S5-G must pass Playback's 32-byte CXPRES identity)
tools in key/file: glslang, shaderc, spirv-cross, spirv-tools
default targets: glsl330.v1, glsles300.v1, spirv.v1
SDK API remains 0.7.0
engine/shader does not include Playback headers
```

缓存不是 Asset Index 源，不进入 `acquirePresentationResource()`，不进入 FrameDigest 或
`PreparedSemanticIdentity`。源 payload 变化必须改变 identity 并走 Playback `prepareReload`。

Player/OpenGL 消费合同由 `ShaderPipelineCache` 测试证明，不在本批改 `cuexis_render_opengl`
或默认 `allCapabilities()`。
