## 2. 计划项对照

1. `OpenGlBackend` 实现 `IPresentationRenderer`。Player 正式帧使用 `prepare`、`activate`、
   `discard`、`resize`、`submit` 和 `present`。
2. `renderPresentationFrame` 保留为 SDK `0.7.0` 兼容入口，供 smoke 的 debug summary
   对照和既有测试使用。像素探针仍由 `lastPixelProbe` 提供。
3. submit 绘制当前帧但不交换缓冲。present 才调用 `SDL_GL_SwapWindow`。准备失败沿用原来的
   OpenGL 错误码，不替换 active cache。
4. rebuild 在当前 context 上释放 GPU 资源后递增 renderer generation，不销毁窗口或 context。
   close 在接口候选尚未丢弃时拒绝，析构仍先释放 GPU 对象。
5. 零尺寸表面让 submit 返回 `presentation.renderer.surface.zero_size`，Player 跳过该帧。
6. 绘制排序和 digest 仍由既有 OpenGL builder 生成，再复制进中立 `DrawSummary`。
   Validation Sink 的 summary golden 没有改。
