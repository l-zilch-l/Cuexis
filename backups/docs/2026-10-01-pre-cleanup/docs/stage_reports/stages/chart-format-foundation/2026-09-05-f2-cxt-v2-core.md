## 1. 交付范围

F2 交付独立的 CXT v2 candidate reader/finite expander。实现位于
`engine/chart/include/cuexis/chart/cxt_v2_loader.hpp` 与
`engine/chart/src/cxt_v2_loader.cpp`，不改变 CXT v1 reader、Chart v4 prepare 或默认
Playback 路径。

当前 Foundation profile 明确支持：

- `moduleKind=prototype` 的单实体 direct invocation，以及 `moduleKind=pattern`；
- integer/beat literal、parameter、slot、repeat index 和单层 affine source；
- 静态 Transform position[0]；
- tap + point requirement、`candidate.lanes4`、`press` 与 lane constraint；
- invocation `startBeat` 平移、参数/slot 默认值与范围校验；
- root、invocation-parent 和同级 emission parent 的有限解析；
- repeat entity/depth/node/requirement 预算和 checked RationalBeat arithmetic。

未登记的 number/vector/boolean/enum、animation module、动态 reference、脚本、随机、
递归和未知 component/requirement extension 均稳定拒绝，不进入 opaque semantic data。
